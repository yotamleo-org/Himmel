**Read the dispatcher copy's content and mtime from one open file.**

The sweep reads the dispositions cache at line 351 and checks its age by pathname at line 353. The background refresh started at line 343 can replace the cache between those two steps. The `stat` then reads the fresh mtime of the new file while the `cat` returned the old bytes. The old bytes pass the age check at line 354. Any ticket that the old copy lists can then print a `DUTY dispatch-owed` line.

The window is only the interval between the `cat` and the `stat`, and the refresh must finish its rename inside it. The effect is a possibly stale operator duty. It does not corrupt data.

Open the cache once on a descriptor. Read the content from that descriptor. Take the mtime from the same descriptor, for example with `stat -L -c %Y /proc/self/fd/N`. Apply the 1800-second check to that mtime. Keep the existing rejection of unread copies. If this file must stay compatible with bash 3.2, use a fixed descriptor number rather than `exec {fd}<`.
