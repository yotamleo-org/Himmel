# macos-poc-suites.txt -- HIMMEL-5007 / HIMMEL-3183: the macOS POC suite set.
#
# os-verify.yml (macOS) runs ONLY the suites named here (run-shell-tests.sh
# --only-list). This list IS the macOS proof: there is no Mac in the fleet, so
# GitHub's macOS runners are the only test bed, and the full corpus is red there
# (macos-cadence red 10-02..10-13; os-verify run 38660360246 failed 27 suites).
# A suite not listed never runs on macOS until it is fixed and added.
#
# One repo-relative path per line; `#` comments and blank lines are ignored.
# Admission rule: a suite is added ONLY with a green macOS log line for it
# (`[PASS] <suite>`). The seed below is every suite that passed in BOTH
#   os-verify  run 38660360246 (eb4a3e64, shards 1-2)
#   macos-cadence run 38401182192 (d0123766, shards 1-8)
# and failed in neither, minus three wall-clock-budget suites (hook-chain-latency,
# run-shell-tests-timing, session-end-timeout-budget) that a shared macOS runner
# can flake. Every suite left out stays tracked on HIMMEL-3183 (the ratchet).
