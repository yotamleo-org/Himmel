# scripts/ci/pr-job-gates.txt — HIMMEL-5524: which diff paths feed which
# pull_request job. Read by scripts/ci/pr-plan.sh from the BASE commit, so a PR
# cannot narrow its own gates except by editing this file, which is a trust path
# (scripts/ci/) and so forces every gate true.
#
# Line format: <group><whitespace><ERE>, matched against each changed path.
# A group is true when ANY changed path matches ANY of its lines. A changed path
# that matches NO line (not even `benign`) is an unknown diff and makes every
# gate true (fail closed). Over-listing a path is safe (the job just runs);
# under-listing is the bug, so when a job starts reading a new directory, add it.
#
# Group names become the `run_<group>` outputs the `plan` job exposes. The
# aggregator-less jobs gated on them report `skipped` (a pass) when false. The
# matrix jobs (node_suites, bun_suites) stay started and skip their steps so
# their required check names still report.
#
# Jobs with no group always run: leak-classes, secret-scan (a secret can land
# in any file), commit-lint, doc-invariants, unchecked-mktemp-range and the
# shell-unit shards (they select for themselves).

benign          ^docs/
benign          ^templates/
benign          ^handovers/
# Safe: no gated job executes or reads a .md file as an input (the audit in
# test-pr-plan.sh follows only code and data extensions), and a docs-only PR
# is the case this gate exists to make cheap. A .md that a suite reads would
# have to be listed in its group above, which would then win over this line.
benign          \.md$
benign          ^LICENSE
benign          ^\.gitignore$
benign          ^\.gitattributes$
benign          ^\.github/(CODEOWNERS|ISSUE_TEMPLATE/|PULL_REQUEST_TEMPLATE)
