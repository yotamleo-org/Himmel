fix(jira): [HIMMEL-8348] a newer operator move supersedes an older operator-authority ruling, and a refused request is closed

The release manager refused every INTAKE that moved a key away from a ruling with operator authority, even when a newer operator decision named that exact move. A request that would supersede an operator-authority ruling is now governed by the newest verified operator decision, by timestamp, that names the key on a version the op touches. A refused request is closed instead of left pending.
