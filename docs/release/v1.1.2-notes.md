# v1.1.2 release notes (HIMMEL-5252)

Curated, user-facing summary of what changed since `v1.1.1`, grouped by theme
(81 merged PRs). `CHANGELOG.md` stays the generated, per-commit record
(`scripts/gen-changelog.sh`, never hand-edited); this file is the readable
version.

**Release date:** 2026-10-11.

## Critical fixes

- **The hook-integrity recorder can no longer brick a session.** An integrity
  failure on a `Stop` hook now skips that hook and lets the session stop
  (HIMMEL-5168); a killed or failed recorder fails open with a notice instead
  of denying every hook (HIMMEL-5171); in a hook chain a member that fails
  integrity is skipped alone and its intact neighbours keep running
  (HIMMEL-5172); a chain member's `Stop` block keeps its own reason
  (HIMMEL-5198).
- **`record-hook-integrity` runs under macOS bash 3.2** (#2333, reported and
  fixed by Goomal, an external contributor; closes #2332).
- Main CI runs on a 7-hour cron plus `workflow_dispatch` instead of every merge
  (HIMMEL-5113); `merge-on-green` refuses on a red main unless the PR is the
  declared fix (HIMMEL-5115, HIMMEL-5134).

## Guardrails and hooks

- **Destructive-command and write fences.** Auto-approve never allows a root
  walk (HIMMEL-5088) and passes `--files0-from`, `cd`-relative walks and
  CR-glued writer operands correctly (HIMMEL-5187); the chokepoint denies any
  `IFS` assignment beside a chokepoint word and no longer depends on the ambient
  locale (HIMMEL-5152, HIMMEL-5153); its relief now voids on `readpipe`,
  executing short options and ripgrep program-running options (HIMMEL-4402,
  HIMMEL-5197, HIMMEL-5210).
- The `/pr-check` literal guard counts `git bisect run` and `rebase --exec` as
  program-running (HIMMEL-5102) and denies a guarded writer behind a git editor
  or alias hook (HIMMEL-5170).
- The live-settings fence decodes `env -S` escapes before judging
  (HIMMEL-4521); the bank-lift write guard trims a classified over-deny
  (HIMMEL-4545).
- Every Bash chain member runs in time linear in its input, with latency RED
  controls (HIMMEL-4729, HIMMEL-5154).
- `himmel-bus` store guard denies direct bus-root access and registration verbs
  from a session's own tool calls (HIMMEL-4829).

## Console and legs

- **`grant-round.sh`**: the console grants one more review round on a signed
  judge record, instead of a hand-pasted counter file (HIMMEL-5058,
  HIMMEL-5126). `write-verdict.sh --bind-reviewed` binds a NO-GO to the reviewed
  head across a test-only or comment-only commit (HIMMEL-5109).
- **Review gate.** A claude-only delta round cannot strand a PR (HIMMEL-5128);
  one post-cap delta round runs when every prior finding is recorded fixed
  (HIMMEL-5185); the ledger confirms each finding append (HIMMEL-5155); gate 4d
  paths survive `quotePath` (HIMMEL-4637, HIMMEL-4641, HIMMEL-5158).
- **Merge gate.** `merge-on-green` re-runs the plugin-version bump check from the
  trusted base-tip checker and requires its success line (HIMMEL-5188,
  HIMMEL-5203, HIMMEL-5208); `merge-forward-check` covers a merge-base with the
  next completed cron or dispatch main run and refuses non-success conclusions
  (HIMMEL-5124, HIMMEL-5137).
- **`console-judge-ro`**, a read-only judge agent with a 1 h cache TTL
  (HIMMEL-5180); judge scratch directories are released when a verdict is
  written and are no longer fully rsynced into tmpfs (HIMMEL-5165, HIMMEL-5173).
- The arming gate runs `brief-lint` on every brief (HIMMEL-4619);
  `close-wrapped-leg` resolves a claudex leg's config dir (HIMMEL-5182).
- Launchers register and bind a session on the himmel-bus, and `arm-resume`
  rebinds a resumed session (HIMMEL-4832, HIMMEL-5201, HIMMEL-5207).
- The tick flags stalled cloud sessions, cloud-route sends already-fixed tickets
  to a local verify, and the cloud environment is declared from the repo with a
  self-check (HIMMEL-5163). Tick and board surface suite-flake ledger rows
  (HIMMEL-5131).
- Autocompact A/B arm and report (HIMMEL-5193, HIMMEL-5196).

## Lanes

- **Lane canary** (`scripts/lanes/lane-canary.sh`): launches one no-op leg per
  lane and reports PASS, FAIL or SKIP with time-to-first-bullet (HIMMEL-5230).
- DeepSeek lane legs start without the external-imports prompt (HIMMEL-5249);
  the OpenRouter lane hands the child a thinking `EXTRA_BODY` so the auto
  classifier works, and the Haiku pin moved to haiku-5.5 (HIMMEL-5248).
- The claudex client-side classifier no longer over-generalises the `rm -rf`
  deny rule (HIMMEL-5077); the claudex jail hook matching and lane scope are
  tighter (HIMMEL-5176).
- A stale codex bank cache refreshes once, bounded, and the doctor warns
  (HIMMEL-5220).

## himmel-bus

`bus wait` verb, a `leg-bus` profile and catalog entry for a live round trip
(HIMMEL-4831); a bus root that enforces `0700` only on `himmel/bus`, with a
failed launcher register surfaced (HIMMEL-5221); the console profile carries
`himmel-bus` so a console registers on launch (HIMMEL-5241). The first live POC
recorded five failures (HIMMEL-4838); see Known issues.

## CI and test tooling

- **Flake handling.** A failed suite is retried once; a pass on retry is a
  FLAKE recorded in a per-repo ledger with a repeat-flake "file a ticket" line
  (HIMMEL-5116, HIMMEL-5121, HIMMEL-5144, HIMMEL-5145, HIMMEL-5147,
  HIMMEL-5156, HIMMEL-5157, HIMMEL-5161, HIMMEL-5169, HIMMEL-5184).
- **Impacted-suite selector** always runs tree-scanning suites, covers
  lowercase and split uninstall callers, template root files and suites that
  name a changed script without its extension, and fails closed on a failed
  temp write (HIMMEL-5114, HIMMEL-5122, HIMMEL-5123, HIMMEL-5132, HIMMEL-5160,
  HIMMEL-5167, HIMMEL-5174).
- `main-sweep-red` persists the newest processed run id, closes a report on a
  green dispatch run and ignores cancelled-shard aggregate failures
  (HIMMEL-5129, HIMMEL-5143, HIMMEL-5146).
- The plugin version-bump check compares against the current base tip and
  passes a PR that never touched the plugin (HIMMEL-5177, HIMMEL-5195).
- Live end-to-end suites: console-kit fixture fleet (HIMMEL-5229), review gate
  and `merge-on-green` against a throwaway repo (HIMMEL-5232), a mock-Anthropic
  turn proving a registered hook fires and denies (HIMMEL-5228).

## Telegram

`/console` queues to a busy armed console and matches a unique name fragment
(HIMMEL-5125); `/console`, the fleet verbs and `/lockdown` accept any case and
the `/verb@botname` form (HIMMEL-5148, HIMMEL-5150); the break-glass allow-rule
refuses symlinks, keeps mode, ignores backups and unless the registry text
equals the approved text (HIMMEL-5112, HIMMEL-5127, HIMMEL-5140).

## Dependencies

One PR bumped every in-policy dependency (HIMMEL-5252, VM-proven): bun 1.4.3,
the CI claude CLI pin 2.1.296, in-range lockfile refreshes, marketplace SHA
pins and the vault template (0.4.71). `claude-hud` and the impeccable,
superpowers and ponytail fork pins were left for HIMMEL-5259 and HIMMEL-5260.

### Station tools: deferred

The three station tools named in the dependency PR did not move on the
operator's station during this release, by ruling:

- **graphify** stays at the installed version; the repo pin is 0.9.80, and the
  update step refuses to swap the install under live `graphify-mcp` sessions.
  It rolls once those sessions are gone (`himmel-update.sh --only graphify`).
- **ast-grep** is an opt-in tool and is not installed on the station, so there
  was nothing to bump.
- **cli-proxy-api** stays at v7.3.15, the repo pin. v8.0.23 is a major bump
  that needs `cli-proxy-lane.sh` `VERSION` and checksum overrides and a
  VM-first upgrade stage (HIMMEL-5267).

## Known issues

- **claudex auto mode does not block destructive actions** (HIMMEL-5264): the
  gateway classifier allowed a force push to main. Run no unattended claudex
  legs; explicit deny rules and a `dontAsk` fallback are in flight
  (HIMMEL-5270, HIMMEL-5271).
- **Guard gaps** (label `guards`): git global options hide `push --force`,
  `reset --hard` and `clean -f` (HIMMEL-5274); no destructive-verb floor for
  `gh` (HIMMEL-5275); the Codex hook chain has no deny list (HIMMEL-5276);
  secret-read, exfil and env-dump verbs (HIMMEL-5277); tag and ref deletion
  (HIMMEL-5278); remote exec beyond `curl | sh` (HIMMEL-5279); process and host
  kill verbs (HIMMEL-5280); `shred`, `truncate`, `dd of=/dev` and
  `chmod -R` (HIMMEL-5281); infra, DB and docker destroy verbs (HIMMEL-5282);
  hook-disabling shapes (HIMMEL-5283); state and vault repos have no
  client-side force-push floor (HIMMEL-5284); `git restore .`, `checkout -f`
  and `reset --keep` (HIMMEL-5285).
- **himmel-bus** has had one live round trip POC with failures recorded
  (HIMMEL-4838); treat the bus as opt-in until its station acceptance closes.
- The lane canary reports a launcher bank refusal (exit 11, for example
  OpenRouter credit below its floor) as FAIL rather than SKIP.
- Windows remains unsupported (epic HIMMEL-4102).
