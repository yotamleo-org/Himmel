The development graph

How a change travels from a console's dispatch to a merged pull request. Five lanes, six phases: the operator rules, the console dispatches and verifies, the leg builds, the judge rules when a trust path is touched, and the gates refuse what is not ready. Dashed red edges are refusals, numbered by the exit code that takes them.

This page loads its data over http, so open it from the docs site or a local static server (python3 -m http.server in docs/guide), not from a file.
